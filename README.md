Number Guessing Game Using Python

Project Description

This project is a command-line Number Guessing Game developed using Python as part of the CodeOrbit Tech Python Programming Internship.

The computer generates a random number between 1 and 100, and the user tries to guess it.

Features

- Generates a random number.
- Provides "Too high" and "Too low" hints.
- Tracks the number of attempts.
- Allows users to play multiple rounds.
- Handles invalid number inputs.

Technologies Used

- Python 3
- Random module
- Visual Studio Code

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run "number_guessing_game.py".
5. Enter guesses and follow the hints.

Concepts Used

- Loops
- Conditional statements
- Random number generation
- Exception handling
- User input and output
